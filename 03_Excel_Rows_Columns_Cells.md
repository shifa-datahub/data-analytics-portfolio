# Excel Rows, Columns, Cells, Worksheets and Workbooks

Author:Shifa

## 1. Rows
Rows are horizontal lines in Excel.
They are identified by numbers such as 1, 2, 3.

## 2. Columns
Columns are vertical lines in Excel.
They are identified by letters such as A, B, C.

## 3. Cells
A cell is the box formed where a row and
a column intersect.

Example: A1 means Column A and Row 1.

## 4. Worksheets
A worksheet is a single spreadsheet
inside an Excel workbook.

## 5. Workbooks
A workbook is the complete Excel file.
It can contain multiple worksheets.

## Practical Example

A college can use Excel to store student
names, roll numbers and marks.

| Roll No |  Name    | Marks |
|    1    |  Shaziya |   85 |
|    2    |  Sara    |   78 |
|    3    |  Shifa   |   92 |

## Summary

- Row = Horizontal
- Column = Vertical
- Cell = Single box
- Worksheet = Single sheet
- Workbook = Complete Excel file
