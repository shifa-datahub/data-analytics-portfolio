# Introduction to Microsoft Excel

Author: Shifa

## What is Excel?

Microsoft Excel is a spreadsheet application
used to organise, calculate and analyse data.

## Important Excel Terms

1. Workbook - An Excel file.
2. Worksheet - A sheet inside a workbook.
3. Row - A horizontal line of cells.
4. Column - A vertical line of cells.
5. Cell - The box where a row and column meet.

## Uses of Excel

- Storing data
- Performing calculations
- Sorting and filtering information
- Creating charts
- Analysing data

## Real-Life Example

A college can use Excel to maintain student
names, roll numbers, attendance and marks.

I will learn Excel functions and practise
