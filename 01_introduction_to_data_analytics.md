# Introduction to Data Analytics

Author: Shifa

## What is Data Analytics?

Data Analytics is the process of collecting,
cleaning, organising and analysing data
to find useful information and make decisions.

## Why is Data Analytics Important?

- Helps businesses make better decisions.
- Identifies patterns and trends.
- Improves performance.
- Helps solve problems.

## Types of Data Analytics

1. Descriptive Analytics
2. Diagnostic Analytics
3. Predictive Analytics
4. Prescriptive Analytics

## Data Analytics Process

1. Data Collection
2. Data Cleaning
3. Data Analysis
4. Data Visualisation
5. Decision Making

## Tools Used in Data Analytics

- Microsoft Excel
- SQL
- Power BI
- Python

## Real-Life Example

An online shopping company analyses customer
purchases to understand which products are
most popular.
